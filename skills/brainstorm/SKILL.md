# Brainstorm

1. `/ground` first. Your opening question should show you've read the code.
2. Go deeper on whatever is hard to reverse. Skim what is cheap to change later.
3. Capture the agreed design where this repo puts design work — check its `AGENTS.md`. If it says nothing, the conversation is the artifact.

No plan mode and no code until the direction is agreed.

Once agreed, `/iterate`.
